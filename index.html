The RAG Pipeline: Step by Step

When a user asks a question to a Copilot Studio agent grounded in SharePoint, this is the exact sequence:

1

User Sends a Message

User types a question in Teams, web chat, Power Apps, or another channel. Sent encrypted (HTTPS) to the Copilot Studio runtime.

2

Message Moderation

Parses input and filters malicious, harmful, or policy-violating content before any retrieval begins.

3

Query Rewriting & Optimization

Before searching, the system optimizes the query:

  • Clarifies meaning — resolves ambiguity
  • Adds contextual signals — last 10 conversation turns
  • Improves keyword matching — search-friendly variants
  • Parallel queries — generates both keyword and semantic versions
  • Synonym expansion — "limit switch" also matches "position sensor", "auto-wiper limit switches"

Example: "what's the part number for a limit switch?" → keyword: "limit switch part number" + semantic: concept of "replacement component identifier for motion-limiting device"

4

Content Retrieval via M365 Copilot Retrieval API

Queries hit the hybrid index powering Microsoft 365 Copilot:

Lexical Search (BM25)

  • Traditional keyword matching
  • Good for exact terms, part numbers
  • Scores by term frequency

Semantic / Vector Search

  • Vector similarity in embedding space
  • Conceptually related content
  • No exact keyword needed

Combined + ranked using Reciprocal Rank Fusion + metadata signals (SP column metadata, Graph activity, people matching).

How many results?

Standard: top 3 per source. With Tenant Graph Grounding: "greater volume of context with greater precision" + files up to 200MB.

5

Security Trimming (Real-Time)

  • Entra ID delegated auth (OBO) — agent acts as the user
  • Only content user has read access to is returned
  • Permissions checked live — never cached
  • Sensitivity labels enforced
  • Users without access get generic "no results" (no data leak)
6

Summarization & Response Generation

LLM receives: retrieved chunks + original query + custom instructions + history.

  • Synthesizes grounded response
  • Generates citations to source docs
  • Applies tone/format rules from maker instructions

Model: Latest OpenAI model on Azure AI Foundry, within Microsoft Services Trust boundary.

7

Safety & Governance

Content moderation • grounding validation • compliance. No customer data trains any LLM.

✓

Response Delivered

User gets the answer with clickable citation links to SharePoint source documents.

The Semantic Index — Deep Dive

What is it?

A hybrid index (lexical + vector) auto-generated from content in Microsoft Graph. Maps organizational data into an advanced semantic index for search relevance.

🏢

Tenant-Level Index

  • Organization-wide
  • All text-based SP Online files accessible by 2+ users
  • Auto-enabled, no admin setup, cannot disable
  • Every M365 Copilot customer has this
👤

User-Level Index

  • Personalized per user
  • Emails, docs you interact with, docs mentioning you
  • Requires M365 Copilot license assigned
  • Stored where mailbox is located
🔢

Vectorization

  • Content → numerical vectors (embeddings)
  • Similar concepts clustered in vector space
  • Enables conceptual search beyond exact match
  • Word relationships: tech/technology/technologies
  • Synonym capture: praised → elated, excited, amazed

Chunking — What's Known

Exact chunking strategy is NOT publicly documented

Microsoft does not disclose chunk sizes, overlap, or embedding model. Fully managed and opaque.

What IS documented:

Meaningful chunks: System "dynamically indexes documents" and "breaks content into meaningful chunks"
Advanced processing: "Advanced query processing to surface the most relevant information"
Same stack: "Same enterprise-grade retrieval stack that powers Microsoft 365 Copilot"
Output format: Returns "relevant text extracts" / "text snippets" — not full documents
Image/table support: PDF image/table recognition for uploaded files (Dataverse path)

Microsoft Graph & The Copilot Retrieval API

What Microsoft Graph Provides

📊

Content & Signals

  • All SharePoint files, OneDrive docs, emails
  • Who authored, edited, shared content
  • Org chart, distribution groups
  • Recent activity patterns
  • Personalization + social matching for ranking
🔑

The Retrieval API

  • Returns relevant text chunks from hybrid index
  • RAG without replicating/indexing/chunking yourself
  • Automatic query transformations for best results
  • Supports KQL filtering (site, type, author, date)
  • Requires Files.Read.All + Sites.Read.All

Two SharePoint Options in Copilot Studio

Two completely different pipelines depending on which option you pick:

Option 1: File Upload → SharePoint

Upload files area in Add Knowledge

  • Files copied into Dataverse
  • Vector embeddings created
  • Image/table recognition (PDFs)
  • Syncs every 4–6 hours
  • Consumes Dataverse storage
  • No sensitivity labels
  • Max 500 objects, 512 MB files

Option 2: SharePoint Connector

Dedicated SharePoint tile in Add Knowledge

  • Content stays in SharePoint (live)
  • Microsoft Graph + Semantic Index
  • M365 Copilot Retrieval API
  • Real-time freshness
  • No Dataverse storage
  • Sensitivity labels supported
  • Tenant Graph Grounding available

Security, Permissions & Compliance

🔐

Authentication

  • Entra ID delegated auth (OBO)
  • Agent acts as the user
  • Only surfaces content user can read
  • Must be authenticated before results return
🛡️

Security Trimming

  • Real-time RBAC on every query
  • Never cached — always live check
  • SP site/library/file permissions
  • No data leak indication
🏷️

Sensitivity Labels

  • Supported (SharePoint connector only)
  • Included in search trimming
  • Highest-priority label shown in response
  • Password-protected files blocked
📍

Data Residency

  • Index stored where SP site is located
  • EU Data Boundary: EU/EFTA datacenter
  • Multi-geo: all boundaries respected
  • Isolated tenant container
🚫

No LLM Training

  • Customer data NEVER trains any LLM
  • GDPR compliant
  • BYOK supported
  • Encrypted in transit + at rest
⚙️

DLP & Governance

  • Power Platform DLP policies
  • Can allow/block SP as source
  • Sites excludable from indexing
  • Agent-level: disable generative answers
⚠️ Oversharing Risk

Audit SharePoint permissions before enabling. Loose sharing = sensitive docs surfacing to wrong people. Switch defaults to "Specific people", use SharePoint Advanced Management to audit, start with a pilot on well-governed sites.
